SDLCCT-111 — 最貴執行清單：共同中繼資料不重複顯示＋廠別獨立欄與篩選

靜態原型，示範 TopTracesTable 把版本／部門／觸發方式三個 欄位依「目前顯示列表是否全部相同」逐欄位獨立判斷是否摺疊到表格上方 的摘要列；廠別獨立成一欄（不摺疊）；並新增廠別篩選器（沿用 SegmentedFilter，純前端篩選）。本檔案僅供 G1b 設計審核 閱覽，非實際 React 元件；篩選器點擊切換為靜態示意（下方三組表格分別 對應三種狀態，非同一個互動元件）。

狀態一：版本／部門／觸發方式皆相同（AC1）

工具列顯示廠別篩選器（目前選「全部」）＋ 右側三個摘要 chip（版本/ 部門/觸發方式各顯示一次）；表格廠別欄逐列顯示，中繼資料欄不再重複 這三項。
