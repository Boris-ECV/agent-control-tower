SDLCCT-71 — 版本成本時間序列表格:修正前後對照原型

場景取自 Gherkin 情境 14:某 Agent 版本 10/9~10/14 六天每日成本依序為 2.1, 1.3, 2.8, 1.9, 2.4, 1.6(皆 < US$100)。此原型僅展示表格文字內容 差異,不涉及折線圖座標計算或任何樣式變更。

修正前(現況,bug)

formatCurrency 對 < US$100 金額仍整數捨入,六天數值幾乎全部顯示相同整數,與折線圖上明顯的逐日波動不符。

日期10/910/1010/1110/1210/1310/14
每日成本 US$ 2 US$ 1 US$ 3 US$ 2 US$ 2 US$ 2
⚠ 看起來像是持平 / 重複,與圖表波動不一致

修正後(本設計)

formatCurrency 對 < US$100 金額一律顯示 2 位小數,六個儲存格各自不同,忠實反映折線圖上的逐日波動。

日期10/910/1010/1110/1210/1310/14
每日成本 US$ 2.10 US$ 1.30 US$ 2.80 US$ 1.90 US$ 2.40 US$ 1.60
✓ 六格皆不相同,與折線圖波動一致

門檻邊界行為(回歸,不受影響)

>= US$100 的金額維持原本整數捨入 + 千分位,大額金額顯示不變。

輸入值formatCurrency 輸出說明
0US$ 0真正的 0,不受影響
0.02US$ 0.02SDLCCT-70 既有行為涵蓋
99.99US$ 99.99門檻邊界:剛好 < 100
100.4US$ 100門檻邊界:剛好 >= 100,維持整數
1234.4US$ 1,234大額金額,維持整數 + 千分位

本原型為靜態展示,僅用於 G1b 設計審核時讓人類直接看到修正前後的視覺差異。 實際實作變更僅限 frontend/lib/format.ts 的 formatCurrency/formatSignedCurrency,詳見 docs/design/SDLCCT-71.md。
