SDLCCT-110 — 最貴執行清單：執行時間欄、Trace ID 截斷與複製

靜態原型，示範 TopTracesTable 新增「執行時間」欄（從 Trace ID 解析 UUIDv7 時間戳）、Trace ID 中間截斷顯示＋hover 顯示完整 ID＋複製按鈕三項變更。本檔案僅供 G1b 設計審核閱覽，非實際 React 元 件；複製按鈕的剪貼簿寫入與「已複製」計時消失為靠 JS 互動行為，此處 以兩種靜態狀態並列示意。
