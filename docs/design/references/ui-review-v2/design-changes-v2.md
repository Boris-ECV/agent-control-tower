## 一、全站共用規則

### 數字與日期格式（V1）

| 項目 | 原系統 | 改版規則 |
|---|---|---|
| 表格金額 | `US$ 900`、`US$ 90.00`、`US$ 22.08` 混用 | 一律 `US$ 1,234.56`：兩位小數、千分位 |
| 摘要卡片金額 | `US$ 1,746` | 取整數 `US$ 1,746`。卡片看的是量級，表格看的是精確值 |
| 數字對齊 | 靠左 | 等寬數字（tabular-nums），金額欄靠右 |
| 百分比 | `1893.8%` | 一位小數，加千分位：`+1,893.8%` |
| 日期 | `2026年10月6日`、`2026/10/06` 混用 | 一律 `2026/10/06` |
| 日期時間 | `2026/10/06 17:18:13` | 一律 `2026/10/06 17:18:13`，台灣時間 |
| 每日欄位標題 | `2026年10月9日` | `10/9 (五)`，縮短並加上星期 |

### 頁面框架（V4、V5、V6）

- **側邊選單**：每個畫面都會反白目前所在的區塊。Agent 詳情和執行詳情都歸在「Agent 清單」底下，所以進入這兩頁時「Agent 清單」保持反白。原系統在詳情頁沒有任何反白。
- **麵包屑**：頂列左側顯示完整路徑，例如「治理 / Agent 清單 / 訂單查詢客服 / 01a11081-9bb1…a64a41」，每一層都可以點。
- **返回連結**：文字改成上一層的實際名稱。原本執行詳情寫「返回 Agent 明細」，和其他頁的「Agent 清單」、「Agent 詳情」用詞不一致，現在改為「返回 訂單查詢客服」。
- **資料更新時間**：原系統的頂列在儀表板寫「今天（台灣時間）：2026年10月15日」，其他頁只寫「2026年10月15日」。現在每頁都統一顯示「資料更新於 2026/10/15 14:30（台灣時間）」。
- **對比度**：選單分類標題改用 `#667085`，對白底約 4.8:1。次要文字用 `#475467`。狀態標籤加上底色、外框和色點。
- **資料來源**：異常與告警、執行詳情頁底部的「資料來源」說明保留，統一用一條分隔線隔開，放在頁尾。

### 互動（V7）

- 可以點的列（表格列、治理缺口列）在 hover 時加底色，尾端箭頭會變色並往右移一點。
- 可以點的列都支援 Tab 鍵移動焦點，按 Enter 或空白鍵開啟。
- 篩選器一律用分段按鈕，右側顯示「顯示 n / 總數」。

## 四、這次截圖中新發現、但沒有修改的問題

- **預算消耗的分子和分母範圍不一致**：87.3% 是 US$ 1,746 ÷ US$ 2,000。分子包含未登錄的「臨時供應商爬蟲」（US$ 259），分母卻不包含它的預算。只算已登錄的 Agent，消耗約為 US$ 1,487 ÷ US$ 2,000 = 74.4%。卡片寫「尚在預算內」，旁邊的卡片卻預估月底超支 US$ 1,609，兩個訊息放在一起容易讓人困惑。
- **「最貴執行清單」看不出哪筆最貴**：10 筆的預估成本都顯示 US$ 0.05。單筆成本小於 US$ 1 時，建議顯示 4 位小數。截圖沒有更精確的數值，所以樣稿維持 US$ 0.05。
- **漲幅的顯示規則不明**：前期 US$ 14.64 的列顯示百分比，前期 US$ 9.05 的列顯示「新增顯著支出」，推測門檻約在 US$ 10，但畫面沒有說明。
- **「本期」已有定義**：儀表板寫明本期是 10/1–10/15，所以建議第 9 點的「本期沒有定義」只適用於 Agent 清單頁。清單頁應該也標出期間；樣稿把它寫在表格下方的註腳。

## 五、資料說明

- **來自截圖的資料**：
  - 各 Agent 的名稱、部門、負責人、預算、本期花費、預算消耗。
  - 儀表板的卡片數字和期間比較。
  - 告警內容。
  - 「訂單查詢客服」的每日花費、成本標籤、10 筆 Trace ID 與廠別、`01a11081…` 的 3 個 span。
  - 「品質異常分析」的每日花費和標籤。
- **由資料推算的內容**：
  - 執行時間是從 Trace ID（UUIDv7）解出來的。`01a11081…` 解出 2026/10/06 17:18:11，和它的 span 開始時間一致。
  - 增加金額是「本期 − 前期」，用截圖上已經四捨五入的數字算，所以和原系統可能差幾分錢。例如原系統顯示 `+US$ 607`，樣稿顯示 `+US$ 606.95`。
- **推斷**：告警頁的 `order_status` 和 `temp_supplier_scraper`，我分別對應到「訂單查詢客服」和「臨時供應商爬蟲」。依據是模型名稱和治理缺口的描述都吻合，但原系統畫面沒有直接寫出對應關係。
- **示意資料**：
  - 其他 7 個 Agent 的每日花費、版本和標籤。
  - 頂列的更新時間 14:30。
  - 原系統只提供 `01a11081…` 一筆執行的 span 資料，其他 9 筆執行詳情頁的時間軸會顯示「沒有可顯示的資料」，不另外產生假資料。
