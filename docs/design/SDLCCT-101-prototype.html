SDLCCT-101 — 可點擊列共用元件（ClickableRow）

靜態原型，示範套用 ClickableRow 後 Agent 清單列（AgentTable）與執行 列表列（TopTracesTable）在「預設 / hover / 鍵盤 focus」三種狀態下的 視覺呈現（底色、箭頭變色右移、焦點外框）。本檔案僅供 G1b 設計審核 閱覽，非實際 React 元件。
