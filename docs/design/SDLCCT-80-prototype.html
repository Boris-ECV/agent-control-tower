情境一：Hover 顯示該日所有版本數值（十字線＋tooltip）

⚠ 原型限制說明：靜態 HTML 無法重現真實的 onMouseMove/onMouseLeave 事件（這是實作中唯一 驅動十字線／tooltip 顯示與隱藏的機制，詳見設計文件決策 1）。下方用一個 checkbox 切換「顯示 hover 狀態」，純粹是原型示範手法， 代表「游標移動到 D-2 位置時」畫面會是什麼樣子——實際元件中不存在任何 checkbox，游標移出繪圖區（onMouseLeave）時十字線／tooltip 會自動消失，游標移到其他日期位置時會自動切換到對應日期的數值。

✓ Tooltip 列出 entries 全部三個版本 （v1、v2、v3），其中 v3 在該日無資料（byDate(entry)[4] === null）→ formatCurrency(null) 既有行為顯示「—」，不 是本票另外新增的 null 分支。十字線為虛線＋次要文字色，與三條實色折線視 覺上明顯區隔，不會被誤認為第四條資料序列。Tooltip 因游標位置落在繪圖區 右半（x=312 ≥ plotMidX=240）而向左延伸，避免被 viewBox 右 邊緣裁切（與 SDLCCT-79 終點標籤同一套方向判斷原則）。
