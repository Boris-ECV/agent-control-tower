SDLCCT-90 — 版本成本圖折線下方面積漸層填色原型

靜態原型，無需安裝任何套件，直接用瀏覽器開啟即可。規則與設計文件 docs/design/SDLCCT-90.md 一致：每個連續（非 null）且至少 2 點的線段下方畫一個封閉面積， 由線段各點向下封到繪圖區底部（Y = CHART_HEIGHT − CHART_PADDING = 136）； 顏色取自該序列的色票顏色，頂端不透明度 0.15 線性淡出到底端 0；單點線段不畫面積；null 日斷開、不內插、不當 0。 DOM 順序：格線 → <g data-areas>（含 <defs>）→ 折線 → Y 軸標示 → 終點標籤 → hover 覆蓋層。
