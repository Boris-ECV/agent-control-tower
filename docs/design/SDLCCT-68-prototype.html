SDLCCT-68 — sticky header 原型（移除重複「Agent Control Tower」文字節點）

僅聚焦工作區頂部 sticky header 區塊的 before/after；不含側邊欄（側邊欄不變）、 不含頁面其餘內容。涵蓋兩種既有 header 形狀：(A) 含右側日期 meta （cost-dashboard / anomalies / agents / agent-detail 共用形狀）、 (B) 不含日期 meta（trace-detail 專屬形狀）。
