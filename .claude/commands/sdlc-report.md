---
description: Produce session report, or weekly retro when called as /sdlc-report weekly
---
Delegate to the reporter subagent. Default: session report
(templates/session-report.md) from this session's activity + recent
metrics events. If the argument is "weekly": aggregate
metrics/events.jsonl per docs/07 §2-3 into templates/retro-report.md
and save as metrics/retro-<YYYY-MM-DD>.md. Present the result to the
human in 繁體中文.
